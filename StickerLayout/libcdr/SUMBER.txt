Alat libcdr untuk membuka CDR tanpa CorelDRAW
==============================================

Printech menjalankan cdr2xhtml.exe sebagai proses terpisah untuk membaca file CDR, lalu memakai CorelDRAW hanya bila
alat ini gagal (keputusan 2026-11-06; kode: kelas Libcdr di StickerLayout/Core.cs). Alat ini menulis satu SVG per
halaman, dan semua warna di dalamnya sudah diubah menjadi RGB.

Semua exe dan DLL di folder ini diambil apa adanya, tanpa diubah, dari paket MSYS2 UCRT64 (https://www.msys2.org).
Sidik SHA256 setiap paket dicocokkan dengan https://packages.msys2.org pada 2026-11-07. Folder ini hanya berisi
cdr2xhtml.exe dan DLL yang dibutuhkannya (dicari dari tabel impor exe dan DLL).

Teks lisensi lengkap ada di folder lisensi/. Paket libcdr tidak menyertakan teks lisensinya, jadi
lisensi/libcdr/COPYING.MPL diambil dari repo libcdr.

Catatan keamanan: zlib 1.3.2 punya CVE-2026-85091 pada fungsi gzwrite (menulis file gzip). libcdr hanya membaca,
jadi fungsi itu tidak dipakai. Perbarui paket bila MSYS2 menerbitkan zlib yang sudah diperbaiki.

Cara memperbarui: unduh paket versi baru dari https://mirror.msys2.org/mingw/ucrt64/, cocokkan SHA256 dengan
https://packages.msys2.org, bongkar dengan tar bawaan Windows, lalu salin cdr2xhtml.exe dan DLL yang dibutuhkannya ke
folder ini. Perbarui tabel di atas, lalu jalankan pemeriksaan otomatis aplikasi.
